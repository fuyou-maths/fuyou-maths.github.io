关于

我是蜉蝣——寄蜉蝣于天地，渺沧海之一粟。

北京科技大学金融工程专业在读，辅修数学与应用数学双学位。以数学为根，向四方求索——一边是市场、风险与定价，一边是公理、证明与模型；再往外，是人文社科的辽阔，与计算机、人工智能的疆界。

朝生暮死，故不忧远方，只问当下。蜉蝣于天地之间，渺小如沧海一粟，却从不停止向光飞行。

学 进行中

AI 辅助教材学习流水线

Python · OCR · LLM · 知识图谱

把整本教材变成可学习产物的七阶段流水线：OCR 解析原文 → 章节分解 → AI 生成讲解笔记 → 代码验证 → PDF 渲染 → 思维导图 → 知识图谱。已完整跑通《R 语言》（12 章 66 节）与《金融风险管理》（29 章 197 节）两本教材，产出带图、带例、带代码验证的中文精读笔记；指定任意教材即可继续扩展。

卷 进行中

AI 试卷命制系统

Python · LLM · LaTeX

面向教学的 AI 出卷工作流：从教材 / 材料 PDF 自动提取知识点，按学科模板生成题目与答案解析，LaTeX（xelatex + ctex）排版输出可直接使用的试卷 PDF。支持人工校验修正、按学科沉淀题库并复用；OCR 采用 PyMuPDF → MinerU → PaddleOCR 三层回退，公式图表多的教材也能稳定解析。

演 进行中

Claude Code 版 PPT 工作流

Claude Code · pandoc · MindShow

一套「说需求就出 PPT」的工作流：先确认场景与受众，再生成大纲与 Markdown，最后出图迭代。含公式的课件走 pandoc 渲染，通用演示走 MindShow / AiPPT，把一次 PPT 制作从几小时压缩到十几分钟；改稿也只需改文字，重出即可。

潮 接近完成

巨潮 A 股定期报告批量下载器

Python · 爬虫 · 并发下载

覆盖沪深北全市场上市公司的年报 / 半年报批量下载工具：按披露月份智能过滤无效请求，数据量过大时自动二分拆分日期区间，断点续传 + 原子写入防损坏，多线程并发下载，修订版自动去重，并输出覆盖率报告便于查漏。适合课程协作 / 课题组按「年份 × 类型」分工后合并。

记 进行中

教材笔记标准化整理流水线

MinerU · 排版标准化

把杂乱的教材扫描件 / PDF 变成排版统一、可复用的笔记：MinerU 解析出 docx / markdown / LaTeX 三种产物，再按参考排版规范整理润色。已处理《解读中国经济》《马克思主义基本原理》《马克思主义政治经济学》，目标是让每一本书的笔记都长一个样、好查好引用。

行迹

一路走来 · 从近到远

每一段经历，是一个角色、一段时间、一件在做的事。

  1. 2026.07 – 至今

    大数据2602班 小班主任 · 经济管理学院

    协助辅导员开展新生班级管理与引导工作，帮助同学们迅速适应大学环境和大学生活，及时完成从「高中生」到「大学生」的身份转换。

  2. 2024.09 – 至今

    团支书 · 金融232班

    负责班级团务工作，积极开展组织生活和推优入党，配合班长开展班级管理和班级建设。

  3. 2024.03 – 至今

    学业讲师团 · 经济管理学院

    讲师 → 团长
    • 2024.03 – 至今 讲师

      积极开展朋辈讲师业务，截止目前，共一对一辅导、一对多辅导讲授百余次，并讲授微积分、微观经济学习题课，参与并主持微积分模拟卷5次，制作电子讲义和电子笔记10余份。

    • 2025.07 – 至今 团长

      参与学院学业和学风建设，主持学院学业讲师团的业务工作，优化讲师团的内部管理，正在尝试运用AI制作试卷生成器和电子笔记生成器。

  4. 2024.03 – 2026.03

    志愿服务指导中心 · 项目执行组组员 · 校团委

    主要参与部门的值班工作：为同学们进行工时的审核与添加，参与长期志愿服务项目调研2次，参与组织学校志愿服务活动1次。

  5. 2023.10 – 2026.06

    新闻宣传中心 · 经济管理学院

    三年 · 志愿者 → 部长 → 副主任
    • 2023.10 – 2024.07 推送运营部 · 志愿者

      学习并了解宣传的相关技能，初步尝试推送制作。

    • 2024.07 – 2025.07 运营策划部 · 部长

      参与学院部分推送的制作和修改，初步培养同学的宣传技能。

    • 2025.07 – 2026.06 运营策划部 · 学生副主任

      共同负责新闻稿上传、学院官方微信公众号的运营、学院推送的制作与审核，召开宣传技能培训会，培养同学的宣传技能：推送制作和新闻稿撰写，并配合学院团委开展各项具体工作。工作的一年间，部门共制作并发布推送300余篇，上传新闻稿60余篇，累计浏览量30万+。

  6. 2023.09 – 2024.07

    创新创业委员 · 工商2302班

    负责班级创新创业工作的转达，为同学们构建起创新创业相关知识理论的初认识，建立好校院班三级创赛通知的桥梁。

  7. 2024 – 2027

    数学与应用数学（双学位）· 北京科技大学

    申请数学与应用数学的双学位，探索数学的理论之美和应用之美，补全公理、证明与模型的那一半，主要课程有微分几何、近世代数、复变函数等。

  8. 2023 – 2027

    金融工程（主修）· 北京科技大学

    从随机过程到衍生品定价，把「模型」与「市场」两套语言放进同一套训练，主要课程有金融工程学、金融市场、随机过程等。
